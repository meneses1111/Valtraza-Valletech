# Valtraza

Valtraza es el sistema web de ValleTech para gestionar servicios de mantenimiento y reparación de computadores. El administrador gestiona las cuentas de técnicos; los clientes no tienen cuenta.

La aplicación utiliza Laravel, PostgreSQL y vistas Blade con Bootstrap. Estas páginas describen los bloques base y acceso implementados. Los módulos restantes y la publicación del libro están pendientes.
