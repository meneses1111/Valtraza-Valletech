# Valtraza

Valtraza es el sistema web de ValleTech para gestionar servicios de mantenimiento y reparación de computadores. El administrador gestiona las cuentas de técnicos; los clientes no tienen cuenta.

La aplicación utiliza Laravel 12, PHP 8.3, PostgreSQL 18 y vistas Blade con Bootstrap. Contempla registro de clientes y computadores, asignación de servicios, diagnósticos, mantenimientos, reparaciones, repuestos, supervisión y consulta pública por código.

Este libro contiene los requisitos, la organización del código, la instalación y el uso por rol. No se incluyen cuentas de clientes, inventario, solicitudes virtuales, archivos adjuntos ni recuperación de contraseña.

La documentación acompaña al código. La ejecución de la matriz oficial y sus dos ciclos corresponde al responsable de pruebas. La publicación del GitBook como sitio se realiza al cerrar la entrega; disponer de estos archivos no significa que el sitio esté publicado.
