# Valtraza

Valtraza es el sistema web de ValleTech para gestionar servicios de mantenimiento y reparación de computadores. El administrador gestiona las cuentas de técnicos; los clientes no tienen cuenta.

La aplicación utiliza Laravel, PostgreSQL y vistas Blade con Bootstrap. La documentación se organiza por módulos y explica sus recorridos de uso y sus reglas principales. La publicación del libro y los módulos de supervisión y consulta pública están pendientes.
