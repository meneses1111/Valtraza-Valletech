# Criterios de elaboración del manual

Las referencias compartidas en Moodle se utilizan para organizar un manual original de Valtraza. Sus instrucciones institucionales pertenecen a las organizaciones que las publican; no se trasladan como nuevos requisitos académicos del proyecto. Consulta realizada el 18 de noviembre de 2026.

| Referencia del curso | Uso en la entrega |
| --- | --- |
| TechSmith, Cómo hacer un manual de usuario | Lenguaje sencillo, tareas ordenadas, índice, imágenes y pasos con resultados comprobables. |
| UNPA, Plantilla Manual de Usuario | Introducción, documentos relacionados, descripción del sistema, ingreso, interfaz, procedimientos por usuario y guía de botones. |
| Junta de Andalucía, Guía de Elaboración Manual de Usuario, versión 01.06 | Organización y mantenimiento del documento, orientación a las funciones y ayuda al usuario. Se consultó como guía, sin reutilizar su diseño institucional. |
| DNP, Guía para la elaboración del manual técnico y de operación | Separación entre el uso cotidiano y la instalación, configuración, arquitectura y operación técnica, que se documentan en el GitBook. |
| Extracto de Google Books sobre manual de usuario mostrado en Moodle | Identificación del manual como apoyo para las personas que utilizan el sistema. La página enlazada no pudo recuperarse; se utilizó únicamente el fragmento visible en la captura del curso. |

## Verificación del contenido

Los nombres de las opciones y las reglas se contrastaron con las vistas Blade, las rutas y los servicios del proyecto. Las seis capturas del manual proceden de las evidencias del ciclo 3, con datos de prueba. Los códigos de seguimiento ya aparecen ocultos en las capturas administrativas utilizadas.

La historia del video aplica los siete elementos del PDF del curso Unidad 3 Tema 1 Moodle Cierre Sustentación Proyecto ADI USC 2025 A: personaje, problema, guía, pasos, desafío, riesgo y final. El caso narrado es ficticio y las funciones mostradas corresponden al alcance de Valtraza.
